# Benton K9 — Site Shell

Simple static site scaffold for a K9 handling & training website.

Quick start

Install nothing — open `index.html` in a browser, or run a local server:

```bash
# from the project root
npm start
```

This runs a tiny static server (via `npx http-server`) on port 5000. Then open http://localhost:5000

Files
- index.html — homepage
- training.html — training programs
- about.html — about page
- contact.html — contact info
- css/styles.css — basic styles
- js/main.js — tiny UI script

Customize content, images, and styles as needed.
